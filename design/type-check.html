Type check: words at each rendered text size

Checks the type rules in DESIGN.md. Serve the repo folder (python3 -m http.server 8767) and open http://localhost:8767/design/type-check.html. Opened straight from disk it can't read the dashboard frames.

Each page is measured in a 1400 px window. The review strip, top bar and screen-reader-only text are left out. Chart text is measured at its rendered size. With larger text, any size below 15 px is marked in red. Print sizes are set in pt in the print CSS; check them in DESIGN.md.

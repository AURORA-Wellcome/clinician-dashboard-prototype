# AURORA clinician dashboard — UI mockups

Interactive HTML mockups for the AURORA clinician dashboard, prepared for clinician working group (CWG) review.

## Viewing

Open any `.dc.html` file in a browser (no build step). The current working version is **AURORA Dashboard Clinical.dc.html** — an EHR-style look with three views (A · Caseload triage, B · Patient detail, C · Session prep), each with four review variants switchable from the scaffold strip at the top.

- `AURORA Dashboard Clinical.dc.html` — current: clinical/EHR aesthetic, single-track estimated severity, visit-order caseload, Tier-1 crisis flow
- `AURORA Dashboard Mockups.dc.html` — earlier version, Industry design system
- `AURORA Dashboard Mockups Classical.dc.html` — earlier version, Classical design system
- `support.js` — shared runtime the pages load; keep alongside the HTML files
- `_ds/` — design-system stylesheets/bundles the earlier versions reference
- `uploads/` — source design reports (v4/v5) the mockups were built from

All patient data is pseudo-realistic and fictional.
